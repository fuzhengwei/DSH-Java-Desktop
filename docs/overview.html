DSH Java Desktop · 架构总览

一款开箱即用的「数字人」AI 智能体桌面端：内置 DSH Java Agent Runtime（含 Java 17 环境），零依赖装完即用。单个数字人胜任编码、绘图、文档、图表等多场景工作；多个数字人经 dsh.v1 / A2A 跨端组建协作团队；插件、Skills、MCP、CLI 随需扩展。

开箱即用 · 单数字人多场景干活 · 多数字人跨端协作 · 插件 / Skills / MCP 可扩展

一、整体架构

桌面端只做壳：React UI 通过 invoke 调用 Tauri 原生能力，通过 127.0.0.1 HTTP/SSE 调用内嵌 JAR；智能体全部能力（ReAct 循环、事件溯源、审批、协作、协议网关）由服务端承载。

蓝色容器：桌面端（本仓库） 绿色容器：内嵌服务端 JAR 黄色块：随安装包分发的运行资源

二、开放协议与远端智能体

服务端实现 DSH v1 与标准 A2A 0.3.x 双协议；远端 DSH / A2A 服务经 Agent Card 发现后接入为「数字人」，由 Remote Agent Gateway 统一转换为 RoomEvent。

三、流式稳定性防护

Tauri plugin-http 的流式转发存在已知缺陷（偶发 chunk / 关闭信号不送达 webview），本项目围绕该问题建立了一套多层防护。

层机制说明
Agent 对话流空闲看门狗120s 无任何字节强制中断（工具长执行期间 SSE 可能静默，不能设太小）
Agent 对话流AbortSignal 打断停止按钮 / 看门狗可立即打断挂起的 reader.read()
Agent 对话流REST 对账兜底中断后按 agentId 拉取服务端会话与消息，比对采纳后静默补齐，不报错
房间事件流指数退避重连1s → 15s 封顶自动重连，afterSeq 按最新 seq 续传（服务端重放 backlog）
房间事件流空闲看门狗 + 轮询10 分钟看门狗兜静默挂死；任务运行期每 5s 补拉事件 + 刷新快照
服务端取消语义完整任务注册表 + FutureTask 取消 + 状态不被覆盖 + 下游级联置 FAILED
服务端失败自动恢复每任务 1 次恢复预算：优先改派（同能力标签优先），无候选则同员重试

四、使用指南

安装与启动

  1. 从 GitHub Releases 下载对应平台安装包；
  2. 安装后启动即自动拉起内置智能体服务（无需 JDK / 数据库）；
  3. 设置页「智能体服务连接」确认服务就绪。

模型配置

  1. 设置 → 选择渠道模板，填 Base URL 与 API Key；
  2. 「同步模型」拉取上游列表或手输模型编码；
  3. 「保存模型」自动激活，顶部选择器切换运行时模型。

数字人协作

  1. 设置 → 数字人目录 →「添加数字人」（自动探测 Agent Card）；
  2. 对话中邀请成员进房间；@成员 定向派发或直接描述目标自动分工；
  3. 任务面板跟踪 DAG 执行、产物与审批。

开发运行

npm install
npm run tauri dev

构建发布

npm run tauri:build
# = agent:build + agent:copy + agent:runtime + tauri build

服务端改动同步

  1. 在 ../deepseek-harness-java 修改并 mvn package；
  2. 覆盖 resources/agent/deepseek-harness-java-app.jar；
  3. 如遇 Permission denied，删 src-tauri/target/debug/agent/ 缓存再构建。
