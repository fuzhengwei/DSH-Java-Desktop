## 排查"对话什么都没提示就结束"（agent 服务端）

- 现象：发消息约 700ms 后空 done（chunks=0），无内容/无工具/无错误。
- 根因链：模型请求失败 → DeepSeekAdapter.publishError 想 log.error → 运行中的 JAR 类加载不到 logback `ThrowableProxy`（另有 mybatis `ExceptionUtil`、`TerminalSessionStatus` NoClassDefFoundError）→ 错误被静默吞掉，ReactLoopAgent 正常收尾推空 done。脏 JAR 由增量构建/打包中断导致（运行 JAR 与新构建 JAR 的 5 个项目模块哈希不一致）。
- 处置：`mvn clean package -DskipTests`（在 /Users/fuzhengwei/DevOps/deepseek-harness-java）→ `npm run agent:copy` + 手动 cp 到 src-tauri/target/debug/agent/（dev 模式下 Tauri 实际加载这里）→ kill 旧进程（62744）→ 后台启动新服务。
- 重建后效果：错误能正常记录（log.error 恢复）并把失败作为 chunk 推给前端（"模型请求失败，正在重试…/⚠️ LLM 调用失败…"），不再是空白结束。
- 遗留配置问题：默认渠道 default 指向本地 waliapi（127.0.0.1:8777，provider=deepseek，model=glm-5.3-flash），但该上游无此模型候选 → "No available upstream candidate"；agnes 渠道（agnes-2.0-flash，apihub.agnes-ai.com）验证可用。建议在设置里激活 agnes 渠道。
- 当前运行态：新 agent 服务以后台任务方式跑在 127.0.0.1:64380（PID 81340），agent-runtime.json 已写入对应记录；桌面 App 重启后会自动拉起新 JAR。注意本机 shell 有 http_proxy，curl 直连 127.0.0.1 需 env -u 清代理，否则得到 502 假象。
